# MarkAdelMounirGad.github.io
## Local Admin Editor

Open `admin.html` on the published GitHub Pages site.

Default password: `mark-admin`

The password can be changed inside the editor, but it is stored only in that browser. This is not server-side security. The editor downloads updated files; upload them manually to GitHub to publish changes.

Publishing workflow:
1. Download `contact.json` and replace the repository copy.
2. Download `Mark_Adel.vcf` if you want to keep the static file current.
3. If a new photo was selected, upload it into `assets/images/` using the exact filename shown in the photo path field.
4. Commit the changes in GitHub.
